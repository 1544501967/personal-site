# 📋 项目背景

电商运营中，财务核算流程复杂且分散：商品成本、平台佣金、物流、退款、广告投放等数据散落在淘宝、抖音等多个平台，运营人员需要手工拉取、清洗、汇总，才能算出一笔订单或一个单品的真实利润。流程繁琐、易出错，且严重依赖经验。

针对这一痛点，基于 LangChain 框架开发了一款集成私有经营数据的财务分析智能体，将自然语言查询与自动化利润计算打通，实现从「问一句」到「出结果」的全链路闭环。

> **一句话总结**：让运营用自然语言完成利润计算与业务查询，把多平台财务核算从「手工搬砖」变成「对话即结果」。

# 🎯 项目目标

- 支持自然语言查询利润、GMV 等核心业务指标
- 整合多平台电商数据，建立标准化的私有数据资产
- 通过多智能体协作，自动拆解复杂业务问题
- 将财务核算流程封装为对话式交互能力

# ✨ 功能特性

- 🧠 **多智能体意图识别**：基于多智能体框架构建意图分类 + Agent 调度系统，将复杂业务问题自动拆解为可执行的子任务并协作处理
- 📊 **私有数据闭环**：整合淘宝、抖音等平台业务数据并进行标准化处理，为智能分析与 AI 应用提供高质量数据资产
- 🧮 **业务分析工具集**：开发数据计算类工具（GMV、利润等指标计算），实现基于多平台电商数据的自动化业务分析
- 💬 **对话式交互**：将复杂利润核算与业务分析封装为对话能力，支持自然语言完成利润计算、指标查询与业务问答

# 📐 核心流程

```
用户自然语言提问
   ↓
意图识别（利润计算 / 指标查询 / 业务问答）
   ↓
Agent 调度 → 任务拆解
   ↓
调用数据计算工具（GMV、利润等）
   ↓
私有数据查询 + RAG 上下文增强
   ↓
结果生成与返回
```
